# v0.2.0：脚本中心、原生 MVU 与前端卡兼容大更新

适配 **dsh 0.1.2-rc.1**，要求 **Node.js 24**。这是 0.x 阶段的大功能版本。

## 主要更新

- **统一脚本中心**：在「设置 → 脚本」管理全局、预设和角色脚本；支持源码、变量、按钮、文件夹、排序、导入导出、启停与运行诊断。保存使用修订冲突保护，失败保留草稿。
- **原生 MVU**：支持初值 JSON/YAML、脚本就绪门控、正常 stop 后的自动变量更新、幂等保存和失败重试。纯官方导入入口适配到原生执行器，修复 Zod 命名空间兼容。
- **剧情变量持久化**：消息、聊天和脚本变量绑定当前剧情，经历史校验、逐表冲突检测、锁与 WAL 保存；重启、分支、回退保持隔离。备份、恢复及刷新统一放到设置。
- **前端卡显示和交互**：补齐真实聊天快照、同剧情跨卡面事件、受保护的消息重绘，以及有界消息选项。可信按钮只填入当前会话草稿，不自动发送。
- **状态栏兼容修复**：按受限条件补出卡片原有 MVU 状态栏，支持只读聊天快照和旧版高度通知；修复纯文本回复选项缺失、重复快照刷新和卡片折叠留白。
- **世界书与消息接口**：扩展新旧世界书目录、绑定与条目操作；消息正文修改通过独立分支完成，变量及消息页操作保留剧情事务边界。
- **统一设置体验**：调整保存栏、分区间距和窄屏导航，补齐表单标签、草稿保护、语言切换失败回退及变量恢复校验。

## 升级说明与兼容范围

升级前备份 Tavern 数据目录及自定义脚本，升级后重启宿主。宿主依赖仍锁定 0.1.2-rc.1。

第三方代码继续在 `sandbox="allow-scripts"` 的独立 iframe 内执行。直接读写父页面 DOM、依赖父窗口 Vue/SillyTavern 的旧脚本不自动获得兼容；自定义 MVU 框架保留原代码。仅在首次加载绘制、没有订阅变量变化的状态栏仍可能需要单卡适配。

后台脚本管理已移入设置。卡面重绘只读，不重新提交模板变量；正常 stop 才提交自动更新。旧版本已经混合的跨分支历史不能自动推断归属。

详细说明：[酒馆助手兼容](https://github.com/Amakurai/dsh-liketavern/blob/v0.2.0/docs/TAVERN_HELPER.md)、[宿主兼容记录](https://github.com/Amakurai/dsh-liketavern/blob/v0.2.0/docs/HOST_COMPATIBILITY.md)、[更新日志](https://github.com/Amakurai/dsh-liketavern/blob/v0.2.0/CHANGELOG.md)。
