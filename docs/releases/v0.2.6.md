新增关于页、角色导入兼容报告与备份恢复，修复依赖告警、剧情回滚和界面状态问题。

**版本要求：dsh `0.1.5-rc.2`、Node.js ≥ 24。**

### 更新内容

- **关于与更新检查**：显示插件、宿主版本和 GitHub 项目，检查最新正式发布及兼容性；兼容的新版本提供更新命令。当前按钮只检查版本，安装仍在终端完成。旧后台未重启时明确提示恢复步骤。
- **导入兼容报告**：导入角色前说明已支持、已知不支持及需确认的脚本、模板和接口；取消不保存，失败可重试，内嵌世界书保持可选。静态检查不保证任意第三方卡兼容。
- **可校验备份恢复**：新增 `dsh-tavern-backup`，支持离线创建、SHA-256 校验、引用预检及向新目录原子恢复，保留宿主历史和配置。
- **角色查找与编辑**：按名称、标签、作者和内嵌书名搜索；修复切换会话时显示旧角色、旧编辑器覆盖新正文和导入失败留下半成品等问题。
- **记忆与回滚**：改善中文检索、候选去重和预算分配，保留归档原文检索；修复删除后重建文件的回滚依赖，保护中断后的恢复日志。
- **依赖与卡面**：移除有已知漏洞的 Showdown，改用固定版 markdown-it / markdown-it-emoji，依赖审计为 0 项已知漏洞；修复深色卡面可读性和关闭交互卡后的内容回退。

### 升级前须知

先备份，完成当前生成及旧模板的跨轮回调，再停止 dsh。新格式化器对标题空格、重复引用、部分旧 emoji 等边缘格式的处理有所变化；已保存回复不会重算。

旧版未完成生成或仍持有跨轮回调闭包的模板日志会明确拒绝升级后重放，并保留数据。遇到该提示时，使用原版本完成相关回调，或在备份后回滚到注册回调之前的楼层，再升级。普通已完成且无活动重放的剧情继续可用。

### 安装 / 更新

下载附件 `dsh-liketavern-0.2.6.tgz`，在下载目录执行：

```bash
dsh plugin --profile web add ./dsh-liketavern-0.2.6.tgz
```

或从固定 GitHub 标签安装：

```bash
dsh plugin --profile web add github:Amakurai/dsh-liketavern#v0.2.6
```

自定义 profile 请替换命令中的 `web`。安装完成后完整重启 `dsh web` 并刷新页面；源码开发挂载需更新源码并重新构建。附件 `SHA256SUMS.txt` 用于校验安装包。
