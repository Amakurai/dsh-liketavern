# v0.4.0 — dsh 0.1.7-rc.2 适配与故障修复

适配 **dsh `0.1.7-rc.2`、Node.js ≥ 24**。宿主 peer 依赖锁定新版，不兼容旧宿主；升级两者后请完整重启后台并刷新页面。

- 迁移到宿主原生 Agent 预设注册器、volatile 设置表单和新版图标接口，修复升级后模式缺失、设置无法保存与界面加载失败。
- 修复远程接口启动故障：strict 校验器使用新版 schema 工厂，移除掩盖契约错误的类型强制转换，并以真实宿主注册器验证注册与撤销。
- DeepSeek 官方预设投影适配 Messages、Files 和 API-key provider 的公开配置/凭据接口；请求仍由同一 AgentLoop 发出，保留同次 prepareCall 冻结的连接与模型能力。
- 对 Messages 不允许的中途 system 位置，合并为首条完整系统提示并给出兼容诊断，保留工具说明；合法位置仍采用完整快照。供应商可能合并相邻同角色消息，不宣称任意 ST 布局均可原样发送。
- 修复新版 tool/developer 消息被当作剧情历史的问题，防止工具结果影响世界书触发、聊天深度和模板变量下标。工具调用/结果的整体边界与附件继续保留。
- Tavern 通知改用合法可扩展消息来源，仍识别旧版 MVU 通知。更新压缩来源、消息恢复和多步请求测试。
- 对齐宿主新的 PTC 子进程运行时，真实工具回归覆盖并行读取、写入确认、失败边界和楼层回滚；卡片脚本与 EJS 的隔离策略不变。
- 设置 entry id 固定为 `dsh-tavern`，供宿主迁移旧 `settings.yaml` 同名节；预设通过注册器管理，不再写入 `.agent-presets`。
- 锁文件更新并修复传递依赖的已知漏洞；发布包仍仅包含构建产物、预设与公开文档。

安装前确认 `dsh --version` 为 `0.1.7-rc.2`。从本 Release 下载 `dsh-liketavern-0.4.0.tgz` 和 `SHA256SUMS.txt`，校验后运行：

```sh
dsh plugin --profile web add ./dsh-liketavern-0.4.0.tgz
```

安装完成后完整重启 dsh 后台并刷新页面。已有角色和剧情留在原数据目录；建议升级前使用备份命令保存快照。

本地验证：干净安装、构建、157 个测试文件（2263 项通过、1 项 POSIX 跳过）、doctor/backup 与 441 文件白名单检查通过。独立安装环境覆盖角色创建、编辑、绑定、开场白、设置保存与旧设置迁移，重启后恢复正常；未调用真实模型。

发布附件必须来自最终提交通过 Windows / Ubuntu CI 后生成的 `npm-package-<commit>`，保留原 tarball 与校验和字节，不重新打包。
