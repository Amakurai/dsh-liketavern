# v0.4.1 — 剧情隔离、分支编辑与事务恢复修复

继续适配 **dsh `0.1.7-rc.2`、Node.js ≥ 24**。这是一次补丁更新，集中修复并发、磁盘故障和分支编辑中的数据一致性问题。

- **事务恢复**：WAL 写入与提交校验楼层归属和完整日志，拒绝损坏数据；修复后继依赖漏判、回滚中断后继续写入及旧提交标记误报完成的问题。
- **卡面写入**：变量和聊天资产追加写入前重新打开楼层，失败时保留未提交状态；校验到提交期间阻止并发换绑。
- **楼层收口**：最终提交失败后可使用原句柄重试；迟到的旧结束帧不能提交新楼层或清除新轮状态。
- **分支编辑**：保留工具调用、附件及其它非文本内容；支持给没有文本块的回复补写正文，清除旧压缩和流式片段，并用真实宿主 Session 校验新历史。
- **剧情隔离**：读取绑定时复核剧情所属会话；分支继承 MVU 放弃恢复标记；兄弟导航清理不会误删并发创建的分支。
- **资产与提示词兼容**：修复空预设顺序、世界书格式和 uid、非 ASCII 整词匹配、outlet 宏及占位符问题；拒绝链接资产、Windows 数据流和链接快照目录。

更多修复见 [更新日志](https://github.com/Amakurai/dsh-liketavern/blob/v0.4.1/CHANGELOG.md)。

安装前确认 `dsh --version` 为 `0.1.7-rc.2`。下载本 Release 的 `dsh-liketavern-0.4.1.tgz` 和 `SHA256SUMS.txt`，校验后运行：

```sh
dsh plugin --profile web add ./dsh-liketavern-0.4.1.tgz
```

安装后完整重启 dsh 后台并刷新页面。角色和剧情仍保留在原数据目录；升级前可用备份命令保存快照。

本地验证：Windows / Node 24.18.0 下，160 个测试文件、2310 项通过，1 项 POSIX 专属用例跳过；构建和 441 文件打包白名单检查通过。测试使用工厂数据，没有调用真实模型。

发布附件直接使用最终提交通过 Windows / Ubuntu CI 后生成的 `npm-package-<commit>` 安装包和 SHA-256 校验和，不重新打包。本 Release 不代表已发布到 npm registry。
