# v0.4.2 — 开场白历史加载与切换修复

继续适配 **dsh `0.1.7-rc.2`、Node.js ≥ 24**。

- 修复新开场白记录的消息顺序，避免后续迁移出现 `system/message requires a protected first surface head`，导致历史无法加载。
- 首条输入补写开场白改用完整轮次；异步读取期间已经开始生成时，不再迟到插入开场白。
- 切换开场白时检查生成状态，并在分支准备期间复核历史变化；新输入到达后拒绝过时切换，保留来源剧情。

本次更新预防新记录产生上述问题，不会自动修复已经无法加载的旧聊天文件。

安装前确认 `dsh --version` 为 `0.1.7-rc.2`。下载本 Release 的 `dsh-liketavern-0.4.2.tgz` 与 `SHA256SUMS.txt`，校验后运行：

```sh
dsh plugin --profile web add ./dsh-liketavern-0.4.2.tgz
```

安装后完整重启 dsh 后台并刷新页面。

发布附件使用最终提交通过 Windows / Ubuntu CI 后生成的安装包，复核 SHA-256 后直接上传，不重新打包。测试使用工厂数据和模拟适配器，没有调用真实模型；不代表已在报告者环境完成旧记录恢复验证。本 Release 不代表已发布到 npm registry。
