# v0.5.0 — dsh 0.2.0-rc.2 适配与分支修复

适配 **dsh `0.2.0-rc.2`、Node.js ≥ 24**。宿主 peer 依赖锁定新版，不兼容 `0.1.7-rc.2`；升级两者后请完整重启后台并刷新页面。

- 宿主包统一升级到 `0.2.0-rc.2`。逐包核对模型请求、工具、系统提示词、会话格式、预设注册与插件使用的五个界面插槽，均无破坏性变化；宿主在步骤失败时补写的工具错误结果不进入剧情历史，楼层按轮收口提交不受影响。
- 修复在工具执行中点击停止后，下一轮请求混入上一轮「步骤收口」与「同轮写入确认」通知的问题。续写指令与记忆压缩等唤醒输入不受影响。
- 修复用宿主消息栏「在新对话中分支」后新会话失去角色绑定、卡面显示为源码、无法继续使用 Tavern 的问题。新会话会得到独立剧情并继承原绑定；分支点之后的记忆与状态只在新剧情中撤销，停在多步轮次中途时连同该层一并撤销，原会话不受影响。

安装前确认 `dsh --version` 为 `0.2.0-rc.2`。从本 Release 下载 `dsh-liketavern-0.5.0.tgz` 和 `SHA256SUMS.txt`，校验后运行：

```sh
dsh plugin --profile web add ./dsh-liketavern-0.5.0.tgz
```

安装完成后完整重启 dsh 后台并刷新页面。已有角色和剧情留在原数据目录；建议升级前使用备份命令保存快照。此前用宿主「在新对话中分支」建出的未绑定会话不会被追溯接管，可在其中重新选择角色，或从原会话再次分支。

本地验证：构建、172 个测试文件（2525 项通过、1 项 POSIX 跳过）、doctor/backup 与 459 文件白名单检查通过。独立安装环境以本机假 DeepSeek 端点完成端到端冒烟：模式切换、角色创建与绑定、HTML 开场白卡面、发信与工具写入、重新生成/回退/编辑/续写/宿主分支、开场白切换、导入预设、设置页各页签与宿主重启恢复；未调用真实模型，不代表生成质量或任意第三方卡已经验收。

发布附件必须来自最终提交通过 Windows / Ubuntu CI 后生成的 `npm-package-<commit>`，保留原 tarball 与校验和字节，不重新打包。
