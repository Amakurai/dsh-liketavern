# v0.5.11：宿主兼容与更新体验修复

开发与构建基线为当前公开最新版 dsh `0.2.2-rc.1`，Node.js 24。`engines.dsh` 和全部 `@deepseek-ai/*` peer 均为 `*`，宿主升级后不会仅因版本号被拒绝加载。开放安装范围不代表所有历史或未来接口都已验证。

## 兼容与更新

- 关于页分别显示插件版本新旧、当前插件及目标发布的宿主版本要求、开发验证基线，并提供[兼容记录](../HOST_COMPATIBILITY.md)入口。
- 有新版时显示明确的更新按钮，展开当前安装方式对应的操作步骤。桌面端可复制固定版本 Git 地址，Web 端可复制安装命令；不兼容或宿主版本未知时明确说明原因。
- Git / tarball 安装由宿主管理器执行升级。宿主原生 registry 更新按钮不适用于这些来源。
- **v0.5.9 及更早版本需要手动升级一次**：旧更新检查器只接受精确版本，不能解析新版的 `*` 门槛，发布新包无法改写已经安装的旧代码。

## 安装与升级

在宿主的插件管理器中添加下面的固定版本地址。已有安装可直接用新地址更新；先备份数据，无需先卸载旧插件。

```text
git+https://github.com/Amakurai/dsh-liketavern.git#v0.5.11
```

Web CLI：

```bash
dsh plugin --profile web add 'git+https://github.com/Amakurai/dsh-liketavern.git#v0.5.11'
```

无法使用 Git 时，可安装本次发布的 [dsh-liketavern-0.5.11.tgz](https://github.com/Amakurai/dsh-liketavern/releases/download/v0.5.11/dsh-liketavern-0.5.11.tgz)，并核对同页 `SHA256SUMS.txt`。

## 修复与验证

包含原生分支来源隔离、旧分支 WAL 归属恢复、模型路由跟随宿主选择、开发依赖安装及 CI 模型接口模拟修复。完整变更见 [CHANGELOG](../../CHANGELOG.md)。此前未成功发布的 v0.5.10 标签保持不变。

独立测试数据目录中，真实宿主 `0.2.1-rc.3`、`0.2.1-rc.5`、`0.2.2-rc.1` 均已通过 tarball 安装、启动、关于信息 RPC、角色保存、Tavern 会话绑定和开场白持久化。后两版还检查了实际关于页；最新版检查了真实 GitHub 更新响应。另已验证 v0.5.9 通过最新宿主原位升级到 v0.5.11，测试数据保留。以上未调用真实模型，不代表穷尽所有模型、卡面或历史数据迁移路径。

发布流程对当前提交重新运行 Ubuntu 与 Windows 全套检查；仅在成功后创建新标签，并上传该次流程生成、核对 SHA-256 的原始安装包。
