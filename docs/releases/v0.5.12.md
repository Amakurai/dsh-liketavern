# v0.5.12：适配 dsh 0.2.2-rc.3、展示渲染与全栈性能优化

开发与构建基线升级至 dsh `0.2.2-rc.3`，Node.js ≥ 24。`engines.dsh` 和全部 `@deepseek-ai/*` peer 保持 `*`，宿主升级后不会仅因版本号被拒绝加载；实际功能验证范围仍以[宿主兼容记录](../HOST_COMPATIBILITY.md)为准。

## 主要变更

- **适配 dsh `0.2.2-rc.3` 与可选服务边界**：对齐 88 项宿主开发依赖与覆盖项，适配 `LlmError.fromFailure` 与模型目录类型；将 `tavern:turn` 注册为 `required: true` 必要上下文，修复关闭宿主可选环境上下文时丢失本轮世界书与记忆的问题；可选注册器（`dsh-agent-preset-registry`、`dsh-typert-registry`）改为按需/纯类型加载并标记 optional peer。
- **消息展示净化、原生 `<details>` 折叠与暗色沙箱适配（#28）**：
  - 剥离独立成行的非标准自定义伪标签（如 `<Adventurer Profile>`、`<status1>`）及同行残余，修复其触发 CommonMark HTML 块吞噬后续 Markdown 代码围栏的问题。
  - 纯文本与 Markdown `<details>` 折叠块改由客户端原生折叠组件配合 `MarkdownText` 渲染（保留引用块、`<br>` 与多行换行、代码语法高亮、嵌套折叠及复制支持，并省去冗余卡面快照传输），复杂 HTML `<details>` 自动回退隔离 `<iframe>`。
  - 交互卡沙箱 `<iframe>` 同步宿主 Web GUI 明暗 `color-scheme`（含实时主题切换与 `document.write` 保持），修复暗色网页搭配亮色系统主题时的不透明白底。
- **事务、分支与全栈性能优化**：加固 WAL 活跃/回滚楼层清单校验、模板可重试收口、原生分支接管恢复与 `v0.5.11` 检查点冷恢复；完成提示词组装、O(N) 记忆预算裁剪、批量 WAL 预写、并行模板分块读取、展示正则合批、流式分片复用、面板增量分页及客户端 bundle 压缩优化。

## 安装与升级

在宿主的插件管理器中添加下面的固定版本地址。已有安装可直接用新地址更新；先备份数据，无需先卸载旧插件，更新后完整重启宿主。

```text
git+https://github.com/Amakurai/dsh-liketavern.git#v0.5.12
```

Web CLI：

```bash
dsh plugin --profile web add 'git+https://github.com/Amakurai/dsh-liketavern.git#v0.5.12'
```

无法使用 Git 时，可安装本次发布的 [dsh-liketavern-0.5.12.tgz](https://github.com/Amakurai/dsh-liketavern/releases/download/v0.5.12/dsh-liketavern-0.5.12.tgz)，并核对同页 `SHA256SUMS.txt`。**v0.5.9 及更早版本首次升级需手动使用上述固定标签地址安装一次。**
