# v0.5.13：适配 dsh 0.2.2-rc.5、展示渲染、模板沙箱加固与全链路体验修复

开发与构建基线升级至 dsh `0.2.2-rc.5`，Node.js ≥ 24。`engines.dsh` 和全部 `@deepseek-ai/*` peer 继续保持 `*`，宿主升级后不会仅因版本号被拒绝加载；实际功能验证范围仍以[宿主兼容记录](../HOST_COMPATIBILITY.md)为准。

## 主要变更

- **宿主基线升级至 dsh `0.2.2-rc.5` 与 `CONTENT_REFUSED` 拒答适配**：将 88 项 `@deepseek-ai/dsh*` 开发依赖、10 项 `overrides` 与安装脚本许可同步升级对齐至公开的 `0.2.2-rc.5`；适配 `0.2.2-rc.4` / `0.2.2-rc.5` 新增的 DeepSeek 流式内容安全拒答错误码 `CONTENT_REFUSED`（先报计费 `usage`、不再归类为可重试的 `MALFORMED_RESPONSE`），在辅助文本收集路径显式给出中文拒答提示并阻止残缺内容归档或提交；逐包核对 `0.2.2-rc.3 → 0.2.2-rc.5` 全部 332 个宿主包，确认系统提示词、事件时序、分支/附件/PTC 与全部客户端 UI 插槽/DOM 契约无破坏性变更。
- **消息展示、原生 `<details>` 折叠与交互卡渲染（#28 / #31）**：修复未闭合 `<summary>`、折行切分、伪标签、反引号代码标签、混合嵌套粗斜体、未闭合/孤立 HTML、引用块围栏与 GFM 表格内 HTML 误判；优化相邻卡片与 `<style>` 归属拆分、`cardFrame` 防重复 `</html>` 拼接、`document.write` 重注入 CSP/桥接、390px 窄屏宽度同步与 1px 溢出滚动条消除，并修复多卡面混排就绪收口与文档顺序复制。
- **EJS 模板引擎与 QuickJS 沙箱加固**：历史消息默认跳过重复 EJS 执行并复用已求值输出快照，防止坏 `<%` 锁死后续轮次；纯文本卡走 V8 快路径并懒加载重模板依赖，保留首轮 `sticky` 闭包跨轮续存与到期回收；移除可写 `globalThis` 中转与 `vm.dump`/`QTS_Dump`，屏蔽原型 `toJSON` 与 `Promise.prototype.constructor` 劫持，加固 `@@if` 单趟只读求值并补充 `v0.5.12` 模板运行时冷恢复夹具。
- **提示词组装、请求投影与角色卡全链路修复**：修复空历史 `depth > 0` 注入、强思考模型非法强发 `off` 与 `efforts: []` 泄漏、`in-history + messagesApi: false` 重复 `TOOLS_SDK`、宿主 `0.2.2-rc.3+` coding agent 身份段剔除与 AI 代答报错/缺凭证指引；修复角色卡解析、已收纳角色保护、WAL 多楼层模拟回滚预检、工作区隔离与 `sessions` 锁死锁、原生 MVU 锚点/来源顺序与热路径性能。
- **离线备份、只读诊断与单会话归档**：支持封闭目录内硬链接组安全备份与恢复并继续拒绝越界链接；`doctor` 复用引用校验并补齐恢复中 WAL、未完成导入、头像 PNG 魔数与草稿超限诊断；完善单会话归档信封计量、错误路径脱敏与完整 WAL 世系校验。
- **实机 Web UI 与安全门禁**：适配宿主 `0.2.2-rc.3+` 四子项设置弹窗顶栏与 overlay 写保护提示，修复弹窗层级、无障碍、嵌套按钮、草稿脏态与多处面板交互细节；清理上游已撤回的 `picomatch` 临时豁免，恢复生产与全量开发锁文件零漏洞、零豁免审计门禁。

## 安装与升级

在宿主的插件管理器中添加下面的固定版本地址。已有安装可直接用新地址更新；先备份数据，无需先卸载旧插件，更新后完整重启宿主。

```text
git+https://github.com/Amakurai/dsh-liketavern.git#v0.5.13
```

Web CLI：

```bash
dsh plugin --profile web add 'git+https://github.com/Amakurai/dsh-liketavern.git#v0.5.13'
```

无法使用 Git 时，可安装本次发布的 [dsh-liketavern-0.5.13.tgz](https://github.com/Amakurai/dsh-liketavern/releases/download/v0.5.13/dsh-liketavern-0.5.13.tgz)，并核对同页 `SHA256SUMS.txt`。**v0.5.9 及更早版本首次升级需手动使用上述固定标签地址安装一次。**
