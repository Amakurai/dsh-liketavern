# v0.5.2 — 记忆检索改进与剧情、卡面和并发修复

继续适配 **dsh `0.2.0-rc.2`、Node.js ≥ 24**。本次汇总 v0.5.1 之后的修复，改善记忆召回，并加固剧情分支、互动卡和并发编辑。

## 记忆检索与维护

- 支持单字名和单字名词，自动入模检索同时识别角色卡名与人设名；减少中英文功能词引起的无关命中。分词使用 NFKC 归一化，全角和半角写法可匹配。
- 自动检索为最新用户输入中的词加权，避免一句短问题被前面的长叙述淹没；续写、重新生成和工具检索沿用各自的查询行为。
- 新增检索别名：会话空闲时使用当前模型，为新记忆补充人名、同义说法和类别。每次空闲最多一次辅助调用，每批最多 12 条；压缩优先，失败或取消后不保存。别名属于可重建的剧情数据，正文变化后自动作废。
- 写入去重改用 0–1 的相似度，减少原始 BM25 分数在小库漏判、大库误判的问题；关键词按两倍词频参与检索，避免关键词较多的摘要被文档长度压低。
- 批量核对文件指纹、复用归档正文、增量更新索引；同剧情的记忆实例通过文件写入登记及时看到工具写入、编辑和回滚结果。
- 无匹配时提供换词检索或读取记忆目录的提示。新增手写开发集、留出集和真实文件系统回归；检索仍以词面匹配为基础，不能保证所有语义改写都能召回。

## 剧情、卡面与编辑修复

- 请求发送前核对冻结计划与当前剧情绑定，换绑或解除及时取消旧轮；未来排队输入、同轮写入通知和步骤通知保持正确的轮次归属。
- 宿主原生分支准备独立剧情，接管失败可重试；续写、开场白切换和楼层操作复核会话身份与历史修订，避免等待期间发布过期结果。
- 卡面桥固定消息与运行时身份，文档重写后旧令牌和许可失效；写入、回执和重绘继续遵守现有沙箱、剧情锁与 WAL 边界。
- 修复多窗口编辑、重复点击和迟到回包引起的角色、世界书、预设、记忆、设置与语言状态冲突；同名资产和 Windows 路径别名保持稳定身份。
- 加固 WAL 整批校验、摘要来源回滚、工作区链接拒绝和写入失败边界。已保存事实的派生索引刷新失败有明确回执，工具输出和错误回显遵守完整 JSON 预算。
- 修复中文整词匹配、会话内换模、AI 代答深度注入重复、官方 MVU 自动启用与旧式宏兼容；`{{pick}}` 在同一聊天中保持固定结果。

## 升级注意

- `dedupScore` 已由 `dedupSimilarity` 取代。旧值不再生效，使用默认值 0.75；新值范围为 0–1，设为 0 可关闭去重。
- `aliasExpansion` 默认开启，会使用当前会话模型进行辅助调用；可在「设置 → Tavern → 记忆 → 检索别名」关闭。关闭后已有别名仍参与检索。
- 已有角色和剧情保留在原数据目录。桌面端先卸载旧 Tavern，再通过「插件 → 添加插件」安装以下标签，最后完全退出并重启桌面端：

```text
https://github.com/Amakurai/dsh-liketavern.git#v0.5.2
```

Web / CLI 可固定安装同一版本：

```sh
dsh plugin --profile web add github:Amakurai/dsh-liketavern#v0.5.2
```

离线安装下载本 Release 的 `dsh-liketavern-0.5.2.tgz` 与 `SHA256SUMS.txt`，核对校验和后运行：

```sh
dsh plugin --profile web add ./dsh-liketavern-0.5.2.tgz
```

Git 标签包含预编译 `lib/`。发布附件使用最终提交通过 Windows / Ubuntu CI 后生成的原始安装包和校验和，不重新打包。

依赖安全：升级 MCP client/core 至 2.2.0、http-cache-semantics 至 4.3.0、source-map-js 至 1.2.2，修复前的 5 项 high 告警清零；干净安装后的全量与生产依赖审计均为 **0 项已知漏洞**。新增行为回归，两平台 CI 加入全量 npm audit。缓存公告的上游争议与独立宿主安装边界见 [依赖安全记录](https://github.com/Amakurai/dsh-liketavern/blob/v0.5.2/docs/DEPENDENCY_SECURITY.md)。

完整变更见 [更新日志](https://github.com/Amakurai/dsh-liketavern/blob/v0.5.2/CHANGELOG.md)。
