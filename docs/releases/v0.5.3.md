# v0.5.3 — 长剧情模板状态修复与持久检查点

继续适配 **dsh `0.2.0-rc.2`、Node.js ≥ 24**。本次针对 [issue #12](https://github.com/Amakurai/dsh-liketavern/issues/12) 的状态膨胀、恢复重放和失败恢复问题，改善长对话与重启后继续生成的体验。

## 模板状态与长对话

- 大型状态改用内容寻址分页，复用未变化的回复和消息变量；生成中的冻结计划与恢复正文独立存储，根引用仍经 WAL 提交和回滚，安全收口后清理不再需要的正文。
- 重放入参共享上下文、历史前缀与 JSON 子结构；没有临时正则的消息不再留下空操作，basic 正则批量执行，减少重复编码、保存和计算。
- 跨轮闭包定期保存完整 QuickJS/WASM 检查点，包含词法变量、共享与循环引用、回调和内部任务。重启或缓存淘汰后恢复最近检查点及尾部日志，已被检查点覆盖的历史操作可释放。
- 检查点压缩和复用分页，清除快照中已释放的内存载荷并裁剪末尾连续空闲页；冻结 v1 恢复引擎，支持登记过的旧运行时，保留旧环境的执行语义。
- 移除原 GENERATE 1 MiB 序列、4096 条消息或操作数等低固定门槛，允许合法的旧大型内联状态恢复。执行预算随输入规模分配，仍保留隔离、超时和资源保护。
- 元数据和指定消息按需读取，缓存已校验的数据块，批量记录 WAL，并发复制分支快照，减少随楼层增长的读写开销。

## 失败恢复与兼容

- 回复已生成但保存失败时，保留 prepared 状态与未提交楼层；下一轮可从正常结束帧补交。无法可靠补交时明确失败，避免静默丢失变量或推进剧情。
- 未知、不兼容或已撤销的检查点运行时在提交前拒绝，不推进根和 WAL。被删除的楼层日志会阻止不可靠的回滚或分支，不能把缺失日志当作恢复成功。
- 兼容原有 JSON 状态、受支持的旧内联日志和 v1 检查点；仍存活的旧环境保持原 helper 语义。更早的 Showdown 活动日志不属于受支持的恢复格式，沿用此前的明确拒绝行为。

本版解决重复保存和无限历史操作积累的问题，但不会使任意脚本的真实活数据恒定大小。完整状态展开仍有 64 MiB 保护，活对象、无法搬移的内部碎片和数据块文件仍占空间；数据块尚未自动回收，分支耗时仍与需复制的文件数有关。不兼容的未来引擎需要专门适配。

## 其它修复

- 修复混合关键词误启用功能词、查询停用词遮蔽其它同字和英文所有格匹配问题；Windows 记忆别名按文件身份处理，合法 `__proto__` ID 不再丢失别名。
- BM25 检索与去重只维护所需的前 K 项，减少大记忆库的排序与扫描；修复基准脚本的基线导入。

## 升级与安装

1. 升级前备份完整剧情数据，先在副本验证长对话、重启后继续生成及分支。
2. 如果使用过定时修改插件上限的脚本，请先停止，避免它覆盖新版代码。
3. 原存档若已删除 WAL 或出现文件损坏，本版不能自动重建缺失数据；不要只备份 `template.json`，也不要为升级手动删除日志。迁移后若需降级，请恢复升级前的完整备份。
4. 桌面端先卸载旧 Tavern，通过「插件 → 添加插件」安装以下标签，再完整退出并重启宿主：

```text
https://github.com/Amakurai/dsh-liketavern.git#v0.5.3
```

Web / CLI：

```sh
dsh plugin --profile web add github:Amakurai/dsh-liketavern#v0.5.3
```

离线安装请下载本 Release 的 `dsh-liketavern-0.5.3.tgz` 与 `SHA256SUMS.txt`，核对校验和后运行：

```sh
dsh plugin --profile web add ./dsh-liketavern-0.5.3.tgz
```

Git 标签包含预编译 `lib/`。发布附件使用最终提交通过 Windows / Ubuntu CI 后生成的原始安装包，核对 SHA-256 后直接上传，不重新打包。本 Release 不代表发布到 npm registry。

本地全量测试 254 个文件通过（3362 项通过、11 项跳过），构建与 511 文件包边界检查通过；另外验证了真实旧版本检查点在新进程恢复、再次保存和第二次冷恢复。测试未使用报告者的原始存档，尚不能替代其环境中的升级验证。

完整变更见 [更新日志](https://github.com/Amakurai/dsh-liketavern/blob/v0.5.3/CHANGELOG.md)。
