# v0.5.4 — 适配 dsh 0.2.1-rc.2，修复正式安装版本脱节

本版要求 **dsh `0.2.1-rc.2`、Node.js ≥ 24**。

[issue #13](https://github.com/Amakurai/dsh-liketavern/issues/13) 中的安装失败来自正式版本未跟上源码：`main` 已完成新宿主适配，但 `v0.5.3` 标签和附件仍声明 `0.2.0-rc.2`。现在安装请使用 **`v0.5.4`**；旧标签与旧附件保持原样。

## 宿主适配

- 适配步骤内 runtime context 刷新，保留本轮冻结的 Tavern 提示词和预设布局载体；多步工具调用继续复用同轮计划。
- 适配新图片加载与渲染接口，以及持久化 Session 和 PTC 工作目录契约。
- 精确锁定本版宿主依赖，同步中英文 README、安装地址和宿主版本徽标。

## 修复与优化

- 修复编辑器关闭、放弃草稿和异步子编辑器恢复时的持久化边界。
- 编辑助手正文时清理旧消息身份关联的脚本状态；记忆别名维护在等待剧情锁后再次响应取消。
- 修复 `trim`、`random` / `pick` 选项和 `addvar` 宏语义，减少世界书长历史扫描、扩深和预算核算中的重复计算。
- WAL 缺少首条或中间记录时拒绝回滚、追加和提交，诊断工具同步识别；兼容旧 before-only 记录和空白行。现有格式不能仅凭序号发现尾部整行或整份日志丢失。
- 临时文件清理不沿入口目录链接进入其它工作区；安装路径祖先的正常挂载继续可用。

## 安装与升级

先备份完整数据。桌面端在「插件」中卸载旧 Tavern，再添加以下地址，安装后完整退出并重启宿主：

```text
https://github.com/Amakurai/dsh-liketavern.git#v0.5.4
```

Web / CLI：

```sh
dsh plugin --profile web add github:Amakurai/dsh-liketavern#v0.5.4
```

离线安装请下载同页 `dsh-liketavern-0.5.4.tgz` 和 `SHA256SUMS.txt`，核对校验和后安装：

```sh
dsh plugin --profile web add ./dsh-liketavern-0.5.4.tgz
```

本版包含 v0.5.3 的长剧情状态和持久检查点修复。已有定时修改插件上限的旧补丁应先停用；缺失或损坏的 WAL 无法自动重建，迁移后降级需要恢复升级前完整备份。

Git 标签包含预编译 `lib/`。Release 附件使用目标提交通过 Windows / Ubuntu CI 后生成的原始安装包和 SHA-256，不重新打包，也不代表发布到 npm registry。回归使用合成资产和模拟适配器，不代表任意第三方卡或真实模型生成效果均已验证。

完整变更见 [更新日志](https://github.com/Amakurai/dsh-liketavern/blob/v0.5.4/CHANGELOG.md)。
