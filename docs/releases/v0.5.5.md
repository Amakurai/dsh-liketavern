# v0.5.5 — 审计修复：分支重放、回滚恢复与展示边界

本版要求 **dsh `0.2.1-rc.2`、Node.js ≥ 24**，宿主依赖与 v0.5.4 相同。

## 修复

- **重新生成 / 编辑消息**：只重放该楼层真正的用户输入，不再把宿主日志里的运行时上下文、同轮写入确认和步骤提示当作新台词；同轮多条输入按原顺序合并，不会把一轮拆成多轮。
- **回滚恢复**：回滚中断时整个剧情的写入都会明确拒绝，避免在部分撤销的状态上继续写；崩溃残留的失效标记不再挡住写入。「设置 → Tavern → 记忆」选中剧情后会提示未完成的恢复，并可「重置回滚游标」，重置后仍需重新回退该楼层。
- **展示净化**：保留 Markdown 代码示例里的标签原文，同时不会因代码区间吞掉 `</think>` 等闭合标签而丢失后续正文。
- **模板沙箱**：`@@if` 只读校验不能再被替换全局或自定义 `toJSON` 绕过；宿主命令入口在第三方代码运行前冻结。
- **聊天世界书损坏**：组装时明确失败，展示和读取工具给出可见提示，不再静默当作空书。
- **备份与诊断**：`card.json` 存储上限统一为 128 MiB 并在写入时检查；超过 16 MiB 的合法中文角色卡不再被 doctor 判为损坏，备份不再整份拒绝。
- 另含卡面预览事件回执、角色卡原型污染键、正则交叠分支检测、原子写目录同步、草稿目录回收等边界加固，详见更新日志。

## 安装与升级

先备份完整数据。桌面端在「插件」中卸载旧 Tavern，再添加以下地址，安装后完整退出并重启宿主：

```text
https://github.com/Amakurai/dsh-liketavern.git#v0.5.5
```

Web / CLI：

```sh
dsh plugin --profile web add github:Amakurai/dsh-liketavern#v0.5.5
```

离线安装请下载同页 `dsh-liketavern-0.5.5.tgz` 和 `SHA256SUMS.txt`，核对校验和后安装：

```sh
dsh plugin --profile web add ./dsh-liketavern-0.5.5.tgz
```

Git 标签包含预编译 `lib/`。Release 附件使用目标提交通过 Windows / Ubuntu CI 后生成的原始安装包和 SHA-256，不重新打包，也不代表发布到 npm registry。回归使用合成资产和模拟适配器，不代表任意第三方卡或真实模型生成效果均已验证。

完整变更见 [更新日志](https://github.com/Amakurai/dsh-liketavern/blob/v0.5.5/CHANGELOG.md)。
